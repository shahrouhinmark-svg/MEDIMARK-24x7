# MEDIMARK 24x7

A GitHub Pages-compatible static website rebrand for MEDIMARK 24x7.

## Files
- `index.html` — page structure, SEO metadata and verified Pharmacy structured data
- `styles.css` — responsive visual system and layouts
- `script.js` — accessible mobile navigation and footer year
- `assets/favicon.svg` — brand favicon

## Deploy
Upload the contents of this folder to the root of the existing GitHub Pages repository (or replace the corresponding files). No build step is required.

## Verification notes
This first-phase version uses the supplied Trade Licence as the source for business identity, proprietor, business category, certificate number, issuing authority, dates and address. Phone, email, business hours, delivery, discounts, doctor/clinic services, accreditations and other unverified claims have been omitted. The brand name `24x7` is retained as part of the official business name and is not presented as a verified opening-hours claim.
